# Big Planetaruim
Working on my Big Planetarium website was a great way to review what I learned in Web Design I. I already knew the basics so writing the HTML and structuring the different sections was relatively easy.

CSS was a bit more frustrating because I had to keep tweaking the styling, spacing and layout to get everything looking the way I wanted. It wasn't difficult in itself, but it was very time-consuming, particularly when small changes had an impact on other parts of the page.

The biggest hurdle was to develop the Galaxy Explorer feature. I had to check with JavaScript. Developing the Galaxy Explorer feature was the biggest challenge. I had to use JavaScript to check the user input and display the correct orbit time. I also tried other inputs, for example, incorrect planet names to see if everything was working as expected.

In Web Design II I want to improve my responsive web design. I’m particularly keen to level up my skills with CSS grid, Flexbox and media queries so I can build websites that look good and work properly across different screen sizes.
